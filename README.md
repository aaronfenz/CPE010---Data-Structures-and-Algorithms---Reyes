# CPE 010 | C++ Programming Laboratory Repository
Compilation of Hands-On Activities

**Overview**
This repository contains my CPE 010 Data Structures and Algorithms laboratory coursework, organized by academic period and hands-on activity (HOA). It brings together C++ source and header files, activity documents, seatworks, assignments, and other supporting materials from the preliminary, midterm, and final periods.

**About**
CPE 010 is a laboratory course focused on using data structures and algorithms to solve computational and engineering-related problems. The activities in this repository include implementing data structures in C++, tracing and testing algorithms, and considering how design choices affect program efficiency.

Some activities include group work or shared materials. Please refer to each activity’s files for its specific requirements and context.

**Course Description**
The course studies data abstractions, data structures, and algorithms that form a foundation for efficient programs. It introduces algorithmic efficiency and complexity, abstract data types, linked lists, stacks, queues, trees, graphs, searching, and sorting.

Through C++ programming, students design algorithms for different data structures and apply them when developing programs to solve engineering-related problems. The course also introduces mathematical analysis and practical performance measurement to compare algorithm efficiency.

**Course Outcomes**
By the end of the course, students are expected to:
- Apply fundamental data structures and techniques to solve engineering-related problems through algorithm design.
- Design efficient algorithms and analyze their complexity.
- Build algorithms using selected data structures and good C++ programming practices.

**Topics Per Period**
**Preliminary Period — HOA1–HOA5**
- Algorithm design, flowcharts, and pseudocode
- C++ programming review and introductory problem solving
- Arrays, pointers, and dynamic memory allocation
- Linked lists and list-based problem solving
- Stacks and queues, including array-based and linked-list implementations
**Midterm Period — HOA6–HOA9**
- Searching techniques, including linear and binary search
- Algorithm complexity and analysis
- Sorting algorithms
- Binary search trees and related tree operations
**Final Period — HOA10–HOA14**
- Graphs and graph representations
- Trees and tree-based problem solving
- Search and sorting analysis
- Algorithm performance measurement and analysis

**Applications Used**
- C++ compiler or IDE: Used to write, compile, and run the .cpp programs. The specific application depends on the local setup.
- GitHub: Used to host the repository and organize the coursework.
- PDF and image viewer: Used to view supporting activity documents and images.

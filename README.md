# CPE010 - Data-Structures and Algorithms - Reyes

### Compilation of Hands-On Activities

This repository contains my CPE010 Data Structures and Algorithms coursework, organized into preliminary, midterm, and finals activities covering HOA6–HOA9. It documents my practice and progress in designing, implementing, and understanding fundamental algorithms and data structures using C++.

The files include hands-on activities, seatworks, assignments, source code, header files, and supporting PDFs. Topics include algorithms, flowcharts and pseudocode; arrays, pointers, and dynamic memory allocation; singly linked lists; stacks and queues; searching and sorting algorithms; algorithm complexity; binary search trees; and graphs.

Each activity folder contains the materials associated with its corresponding exercise. Together, these files serve as a record of my coursework and practical work throughout the term.
